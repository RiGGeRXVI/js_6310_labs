# Snake Telegram Bot

Бот для Telegram, реализующий команды для игры "Змейка".

## Команды
- /rules — описание правил
- /game_stats — показывает текущие рекорды и историю игр

## Установка и запуск
1. Установить зависимости:
   npm install
2. Создать файл .env с содержимым:
   BOT_TOKEN=ваш_токен
3. Запустить:
   npm start

## Проверка качества кода
npm run lint

## Запуск тестов
npm test
npm run test:coverage
