# SNAKE REACT
## Описание
Этот проект представляет собой классическую игру "Змейка", реализованную на React с использованием TypeScript.
Игра поддерживает одновременное отображение и управление несколькими змеями на игровом поле.
## Структура проекта

ui-library — библиотека UI-компонентов: Snake, Field. Хранит логику отображения змей и игрового поля.

frontend — веб-приложение React, использующее ui-library и реализующее логику управления состоянием змей.
## Устновка и запуск
1. Клонируйте репозиторий и перейдите в папку проекта
2. Установите зависимости для обоих пакетов:
    cd ui-library
    npm install
    npm run build

    cd ../frontend
npm install
3. Запустите dev-сервер для фронтенда:
    npm run dev
4. Откройте браузер и перейдите на http://localhost:5173
    Вы увидите игровое поле со змеями, которые движутся и управляются с клавиатуры.

## Управление

Для первой змеи используются стрелки клавиатуры (вверх, вниз, влево, вправо).

Для второй змеи используются клавиши WASD.

## Скрипты проекта

Оба пакета (ui-library и frontend) поддерживают следующие команды:

    npm run dev — запуск в режиме разработки

    npm run build — сборка проекта

    npm run lint — проверка ESLint

    npm run lint:fix — исправление нарушений ESLint

    npm run test — запуск тестов Jest

    npm run test:coverage — запуск тестов с отчётом покрытия кода
